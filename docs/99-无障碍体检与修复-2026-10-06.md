## 2. 已修 · ① 禁止缩放（WCAG 1.4.4）

`index.html` 的 viewport 去掉了 `maximum-scale=1.0`。
现场/仓库在户外强光下看手机（AGENTS §1），不给捏合放大是真问题。

## 3. 已修 · ② 链接不跟随品牌色（59 节点）

`main.tsx` 只设了 `colorPrimary`，而 antd `genColorMapToken.js:22` 是
`colorLink = seed.colorLink || seed.colorInfo` → 全站 `<a>` 落回 antd 默认蓝 **#1677ff**：
既与品牌 `#1f5fd0` 同屏两种蓝，对比度也只有 4.1:1。现显式声明 `colorLink`/`colorInfo = T.brand`。

★ 与「旧主色 `#1f6feb` 躲在 `styles.css`」是**同一类盲区**：躲在第三方默认值里，`VIS-hex` 扫不到。

## 4. 已修 · ③ Select 无可访问名（33 处）

页面级筛选 `<Select>` 内部是 `role="combobox"` 的 `<input>`，不写 `aria-label` 读屏只念「组合框」。

- **rc-select 的转发已核**：`SingleSelector` 用 `pickAttrs(props, true)` 把 `aria-*` 转给该 input
  （`node_modules/rc-select/es/Selector/SingleSelector.js`）→ 传 `aria-label` 即生效，零视觉影响。
- **Form.Item 包裹的不用写**：antd 会给 `label + htmlFor`。
- 6 个共享字段组件（`fields/SelectProject|SelectEquipment|SelectLocation|SelectStdItem|SelectSupplier|ItemSelect`）
  在**组件内**给固定默认名（`antd` 的 `placeholder` 类型是 `ReactNode`，不能直接拿来当 `aria-label`），
  调用点仍可用 `{...rest}` 覆盖。

### ★ 探针的量测盲区（值得记）

axe 只扫「当前渲染出的 DOM」——弹窗/非默认页签里的 Select **扫不到**。
`A11Y-Select有可访问名` 这条静态护栏一上，立刻多抓出 **14 处** axe 没看到的
（`task` 拆分弹窗、`admin` 转交弹窗、`ChangeDetailModal`、`InitiationEditors`、`PriceReferencePanel`、
`DrawingsModals`、以及 6 个共享字段组件）。
**教训：渲染级探针 + 源码级护栏要配对**，单靠任何一边都会漏。

## 4b. 已修 · ⑨ `<Progress>` 无名字 / ⑩ `theme-color` 旧主色

**⑨** `PmWorkbench`（设计进度）、`assembly/Page` 与 `EquipmentsCard`（齐套率）三处 `<Progress>` 补 `aria-label`。
antd 会把 `restProps` 转发到那个 `role="progressbar"` 的 div（`antd/es/progress/progress.js` 的 `omit(...)` 不含 `aria-*`），所以传 `aria-label` 即生效。

**⑩** `index.html` 的 `<meta name="theme-color">` 还是旧主色 `#1f6feb` → 改 `#1f5fd0`。

★ **旧主色已第三次躲过扫描**，值得记：
① `styles.css`（`VIS-hex` 只扫 tsx）→ ② antd 默认 `colorInfo`（`colorLink` 的兜底，见 §3）→ ③ 应用外壳 `index.html`
（`VIS4` 的旧主色断言只扫了 `styles.css`）。所以新增的护栏不再只盯某个文件，**直接拿 `tokens.ts` 的 `T.brand` 当唯一事实源对账**。
