# 11 · 导航上下文（drill-in 后"我在哪"）· 体检与修法

> 起因（客户实测）：**在商务部工作台点开一个项目，侧栏直接跳去「业务 → 项目」**。
> 结论：这不是那一个链接的问题，是**「我从哪个台进来」这一维在系统里根本不存在**。已修，并焊了护栏。

## 1. 病根

| 机制 | 位置 | 后果 |
|---|---|---|
| 侧栏选中 = **按路径前缀反推** | `configs/domain.tsx matchSidebarKey()` | `/projects/TX…` 命中「项目」（比「工作台」前缀长）→ 选中被抢 |
| 台 Tab 条 = `WorkbenchShell` 包着的路由才有 | `App.tsx` | 详情/新建/立项/设计面都在壳外 → **整条台条消失**，切不了台 |
| 返回口写死 | `ProjectHeader:52`、`DesignHeaderCard`、`InitiatePage:177` | 「← 返回列表」一律去 `/projects` → 把从台里进来的人**彻底踢出台** |
| 手机端底部条同构问题 | `MobileLayout.tsx:81-82` | `/m/accept/:id` 匹配不到任何 tab key → `?? '/m'` → **掉回「首页」** |

**跨域跳转共 19 处**（`nav('/projects…')` 14 + 设计面 5 类），另有 `/projects/new`、`/projects/:no/initiate`；全部同一个后果。**不是一处漏了，是缺一个统一机制。**

## 2. 修法（已实现）

**新增"来源"这一维，放在 URL 里**（不放 router state：要能刷新 / 收藏 / 新标签 / 被 e2e 断言）：

```
/projects/TX26003?from=%2Fpurchase%2Ftab%3Dorders   ← 从采购台「采购单」页签点进去
```

| 件 | 作用 |
|---|---|
| `hooks/useFrom.ts::useGoFrom()` | 19 处 `nav('/projects…')` → `go('/projects…')`，自动把**当前 URL（含自己的 `?tab=`）**写进 `from` |
| `useFrom()` / `contextPath()` | 侧栏选中与台/域条的高亮**都按来源算**（`AppLayout` + `DomainShell`） |
| `useBack(fallbackTo, fallbackLabel)` | 有来源 → 「**← 返回商务部工作台**」并回原页签；无来源 → 保持各页原文案与原行为（「← 返回列表」） |
| 四个详情路由挂进 `WorkbenchShell` | `projects/new`、`projects/:no`、`:no/initiate`、`:no/design/:equip` → **台条不再消失**，URL 一个没改 |
| `MobileLayout` 的 `ALL_TABS[].match` | `/m/accept` 归回「仓库」；底部条不再掉回首页 |
| `RequirePerm` 守卫 | 带 `from` 进来却没权限 → 弹回**他来的那个台**（不再一律丢去「我的工作台」） |

**顺带修掉的一处隐患**：`useBack` 台清单**由 hook 按需自取**，不做模块级缓存 —— 模块级缓存会跨账号脏读（切换用户 / 伪装后拿到别人的台名）。

## 3. 证据（全部浏览器实测，只读）

真实点击路径 12/12：

```

  ✅ 侧栏选中=「工作台」   ✅ 台条=["我的工作台","商务部工作台"]
  ✅ 返回口=「← 返回商务部工作台」   ✅ 点返回 → /workbench/sales

```

**修复前后对照**（同一探针 `navprobe2`，5 个落点）：台条消失 5/5 → 保住 5/5；侧栏被抢 5/5 → 保住 5/5（用真实点击时）。

## 4. 护栏（防回潮）

`frontend/e2e/ui.mjs` 新增 5 条，**自建靶、不许"没数据就跳过"**：
`NAV-drill-in 带来源` / `NAV-侧栏不被抢走` / `NAV-台条不消失` / `NAV-返回口是来源台` / `NAV-点返回回原台`。

★ **注入反例自证能红**：把 `useGoFrom` 改成不带 `from` → 探针从 12/12 掉到 **3 通过 / 9 失败**（侧栏=项目、返回口退回「← 返回列表」、点返回落不到原台），随后还原。

## 5. 收尾（2026-09-29 追加，三条都已落地）

| # | 项 | 做了什么 | 证据 |
|---|---|---|---|
| 1 | **行内项目号的同款断言** | 改成**静态护栏**而不是数据断言（数据断言会休眠）：`e2e:static` 新增 `NAV-跨域跳转带来源` —— 台/业务域里出现裸 `nav('/projects…')` 直接红 | 注入反例（warehouse 里加一条裸跳）→ **PASS 27 掉到 26 + FAIL 1**；还原后回绿 |
| 2 | **多级下钻只记上一跳** | `useGoFrom` 改为**来源透传**：本页已带 `from` 就继续带**最初那个台**（回到来源本身/切到别的台时除外，避免自指与骗人的返回口）；并把二级入口（项目详情 →「进入设计 →」/「去立项页」/设计进度卡）也接上 `go()` | 真实点击：`/projects/TX26003?from=%2Fworkbench%2Fsales` → 点「进入设计」→ `/projects/TX26003/design/01A?from=%2Fworkbench%2Fsales`（**来源没被上一跳覆盖**），返回口仍是「← 返回商务部工作台」，点它直接回台 |
| 3 | **无来源时台条仍画（高亮为空）** | `DomainShell`：既不在任何台路径下、又没有 `from` → **不画台条** | 直达 `/projects/TX26003`：台条数=0、返回口回落到默认「← 返回列表」、侧栏正确高亮「项目」；带 `from` 进来时台条照常且高亮来源台 |

> 没做面包屑（`项目 / TX26003 / 设计面`）：有了"来源透传 + 返回口指回最初那个台"，多级的**迷失**问题已经没了；面包屑是锦上添花的导航，做它会再引一层状态与一处新的维护点，当前不值。需要时另开一轮。

**链路/直达复验 9 条 + 真实点击 12 条 = 21 条全过。**

## 7. 补一轮：把「取消/返回口没消费 from」这一类收干净（2026-10-04）

> 触发：用户实测 **商务工作台 → 新建商机 → 取消 → 落到 `/projects`**（不是回商务台）。
> 根因：上一跳 `useGoFrom` 已经把 `?from=/workbench/sales` 记好了，但 `CreatePage` 的取消/成功**写死 `nav('/projects')`，没消费 from**。

### 7.1 契约补充（原 §2 只讲了"跳出去带 from"，这次补齐"进来后必须消费它"）

- **返回口要消费来源**：任何从别处进入的子页面，「取消 / 返回 / 关闭」回 `useBack()` 解析出来的来源（连同来源页的 query/页签），不写死默认目标。
- **成功落点也算返回**：提交成功后去哪要明确；若去详情页，必须继续把来源带过去（`go('/projects/{no}')`），否则详情的返回口会回默认列表。
- **跨域跳转全覆盖**：不只是台上点项目，组件里的"去采购台 / 去车间台 / 立项页的设计"等也要带来源。

### 7.2 本轮改的（5 处）

| 位置 | 修前 | 修后 |
|---|---|---|
| `features/project/CreatePage.tsx` | 取消×2 + 成功后 都写死 `nav('/projects')` | 取消用 `useBack('/projects')`；成功后 `go(新商机详情)`（来源继续透传） |
| `features/project/InitiatePage.tsx` | 立项成功后 `nav('/projects/{no}')` | `go(...)` 带来源 |
| `components/InitiationEditors.tsx` | 立项页「设计」裸 `navigate(...)` | `go(...)` |
| `components/project/EquipmentsCard.tsx` | 项目详情「装配/厂内调试」裸 `nav('/workbench/shop/assembly')` | `go(...)` |
| `components/design/DrawingsModals.tsx` | 设计面「去采购工作台」裸 `nav('/purchase')` | `go(...)` |

### 7.3 护栏加固（原来的盲区）

- **静态 `NAV-跨域跳转带来源` 扩面**：DOMAINS 补 `features/project` 与 `components/`（原来漏了 → `CreatePage` 没人拦）；模式从只盯 `nav('/projects…')` 扩到 `nav('/workbench…')` 与裸 `navigate(`；注释行跳过；例外只留两条（`MePage` 回到电脑版、工作台内 `/admin/users`）并写明理由。
  - **注入反例自证能红**：把 `CreatePage` 取消改回 `nav('/projects')` → `static PASS 41 → 40 + FAIL 1`，还原回绿。
- **UI 行为断言新增** `NAV-取消回来源台`（`e2e:ui`，自建靶）：商务台 →「新建商机」→ 断言 URL 带 `from=` → 点「取消」→ 断言回到 `/workbench/sales`。
