# 25 · 价格库：入口从采购台搬进基础数据

日期：2026-10-07。状态：**已落地**（后端 3 个只读接口 + 前端 1 个新页 + 采购台瘦身 + 5 条护栏）。

## 1. 客户口径

> 「我想做一个完整的入口和一个展示。但是我想把这个入口放到**基础数据**这里，
> 就是我既可以**导入**，又可以**看我导入好的这些数据**。」

拍板的四条：
1. 入口放**基础数据**（与 标准库 / 编号规则 并列）
2. **采购台的价格参考瘦身保留** —— 查价是下单时的高频动作，不该把人赶出去
3. 台账**先按品类分组**浏览（12,431 个物料平铺翻不动）
4. 首屏做**待办式指标**（可点，点了就筛出来），而不是装饰数字

## 2. 为什么拆（拆之前的问题）

「价格参考」一个页签里塞了三件事：

| | 内容 | 性质 |
|---|---|---|
| ① | 选物料 → 历史价 `price-reference/{item_no}` | **干活**：下单时查这个料多少钱 |
| ② | 选物料 → 推荐供应商 `recommend/{item_no}` | **干活** |
| ③ | **历史采购导入** `import-history`（Excel/CSV → 价格库） | **主数据管理** |

页签名叫「参考」却藏着数据导入；且导完只能一个物料一个物料点着看，
**没法回答「我到底导了什么、有没有导歪」**。

拆完：**采购台 = 干活视角，基础数据 = 管数据视角**，两者指向同一张 `supplier_quote`（不建第二份）。

## 3. 库里现在有什么（2026-10-07 实测）

```
56,195 条成交价 · 12,431 个有价物料 · 431 家供应商 · 2025-01-02 → 2026-10-07
其中 ERP 导入 56,189 条（下单自动回写 6 条）
```

★ **但「导了多少条」不是这批数据的价值**，「有多少料真能拿来比价」才是：

| | 物料数 | 占比 |
|---|---:|---:|
| 有 ≥3 家成交价 → **可放心推荐** | **664** | 5.3% |
| 有 2 家 → 可比价 | 2,962 | 10.4% |
| **只有 1 家** → 选不了价 | **9,469** | 33% |
| 标准库里有、价格库一条没有 | 16,152 | 56% |

> 所以首屏那排指标就是这个 —— 「只有一家 9,469」和「从未有价 16,152」都是**待办**
> （点了就筛出来），不是给人看的装饰数。

## 4. 口径单一口径（`services/pricing.py`）

搬到基础数据后最要防的是**同一个数在两处各算**（AGENTS §8.5）：

- `MIN_COMPARABLE = 2` / `MIN_RECOMMENDABLE = 3` —— **只有这一处**
- `stats` 把 `thresholds` **下发**给前端（前端不许写数字；护栏盯着）
- 「均价 / 最近价」台账与「价格参考」共用同一套聚合

`stats` / `items_ledger` / `quotes_by_item` 三个函数是**唯一出口**，路由层不自己写聚合。

## 5. 接口（三个都是**只读**）

| 接口 | 权限 | 用途 |
|---|---|---|
| `GET /purchase/quotes/stats` | `purchase:price` | 首屏健康度 + `thresholds` |
| `GET /purchase/quotes/items` | `purchase:price` | 台账，**一行一个物料**（聚合） |
| `GET /purchase/quotes/by-item/{item_no}` | `purchase:price` | 某物料全部报价 |

筛选：物料号/品名/规格/品牌、品类、供应商、日期区间、来源，
外加两个待办开关 `only_single` / `only_never`。

⚠ 过滤/排序/分页**全在 SQL 里**（库里有 2.8 万个标准库物料，拉回 Python 再排会卡死）。
台账**默认只列有价的料** —— 价格台账不是标准库清单。

## 6. 权限：导入从「采购员」提到「采购经理」

**改动前**：`import-history` 挂 `purchase:edit` → **采购员就能改公司级价格库**。
导错一条会影响后面所有项目的比价。

**改动后**：新增权限码 **`price:import`**，只给 `PURCHASE_LEAD`（采购经理）。

| | 看价 | 导入 |
|---|---|---|
| 采购员 `PURCHASE` | ✅ `purchase:price` | ❌（实测 403 `没有权限：price:import`） |
| 采购经理 `PURCHASE_LEAD` | ✅ | ✅ |
| 财务 `FIN` / 总经理 `GM` | ✅ | ❌ |

价格库页签按 `purchase:price` 过滤 —— **没有它的人看不到这一页签**（铁律 N23 金额分档）。

## 7. 采购台瘦身

- **删**：导入卡 + 导入结果弹窗（原样搬去基础数据）
- **留**：查价 + 推荐供应商
- **加**：一行「→ 去价格库（导入 / 台账）」，带 `?from=`

## 9. 已知限制

1. **台账只按物料聚合**，不支持「按供应商」浏览（要看得先按料筛）—— 一期没做，避免和标准库页抢导航。
2. **导入不做批次留痕表**（沿用旧接口）：只看得到本次结果，没有「谁在什么时候导了第几批」。
3. 「从未有价 16,152」是**标准库里没有任何成交价**的料，其中一部分是压根还没下过单的正常情况，
   不全是"该补录" —— 真要当待办用，得先跟客户确认这个口径。
