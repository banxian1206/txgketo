# 三维登录交互原型 · 2026-10-07

用户要求先体验有技术实现的动态登录页。本项为独立设计原型，不替换正式登录页。

入口：`/design-lab/login-3d/index.html`。原生WebGL生成齿轮、轴套、法兰、螺栓和支撑结构，深度测试、视角响应、金属高光及分解/合拢插值；没有外部依赖、CDN、模型下载、认证请求和存储。使用现有公司logo。普通输入填任意演示内容；密码error为失败示例；成功只展示结果层，不进入真实工作台。

交互：合拢/拆解、暂停/开启动态、显示密码；必填失败定位输入；登录期间禁用重复提交；失败保留演示内容；成功可再次体验。系统减少动态偏好默认暂停、无鼠标视差、缩短结果等待；手机降渲染像素比、表单上下布局。无WebGL时表单仍可演示。

实际验收：1440×960场景可见，模拟失败提示及修改后成功结果已确认；390×844根宽390、表单342，无页面横溢；浏览器控制台无error。JS语法检查通过。概念机械结构不是工程模型，原型的表单示例不代表真实认证或进入业务工作台。
