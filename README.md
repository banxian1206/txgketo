# 同兴高科 项目管理系统（txgketo）

**客户**：广东同兴高科智能装备有限公司（TXGK / 品牌 TXAM）——非标自动化装备与整线制造商
**业务**：商机 → 立项 → 工程设计（设计BOM + 材料BOM）→ 采购 → 仓库 → 制造 → 装配调试 → 发货发运 → 现场安装 → 现场调试 → 客户验收 → 质保售后
**约束**：纯内网私有部署，**不集成任何外部系统**；手机端是主要终端（仓库/车间/现场没有固定办公地点）
**规模**：公司约 30 人使用 → 单机 Docker Compose 部署，不上集群/微服务/Redis

## 三、怎么跑起来

```bash
./dev.sh          # 一键：数据库 → 后端 :8208 → 前端 :5207
./dev.sh stop     # 停后端与前端
```

| 用途 | 地址 |
|---|---|
| 前端 | <http://127.0.0.1:5207> |
| 接口文档 | <http://127.0.0.1:8208/docs> |
| 账号 | `admin` / `admin12345`（上线前必须改） |

**端口**（已登记于 `../PORTS.md`）：前端 5207 · 后端 8208 · PostgreSQL 35432

> ⚠️ **本机 Docker 注意**：compose 文件顶层必须写死 `name: txgketo`，启动必须带 `-f`。
> 本机多个项目都用 `deploy/` 目录，Docker 默认以目录名作项目名会撞车（详见 `../PORTS.md`）。

## 四、开放项（不阻塞开工，随开发确认）

| # | 开放项 | 本稿采用的默认口径 |
|---|---|---|
| 1 | 统计的年度口径 | **按项目 BOM 发布时间**归属；可切换按入库/发运时间 |
